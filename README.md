# MotoDrive - منصة نقل الركاب بالدراجات النارية في الجزائر 🇩🇿

منصة وتطبيق **MotoDrive** لحجز ونقل الأشخاص بالدراجات النارية في جميع الولايات الجزائرية الـ 58، مع نظام التفاوض المباشر على الأجرة بين الراكب والسائق والتتبع اللحظي عبر نظام تحديد المواقع (GPS).

## الميزات الرئيسية
- 🏍️ تطبيق مخصص للركاب، تطبيق مخصص للسائقين، ولوحة تحكم شاملة للمشرف.
- 📍 تغطية شاملة لجميع ولايات الجزائر الـ 58 وبلدياتها.
- ⚡ محرك بحث سريع وفوري للأماكن والبلديات والمعالم.
- 💰 نظام تسعير ذكي وتفاوض مباشر على الأجرة.
- 🔐 تسجيل دخول سهل بحساب Google أو بالبريد المباشر وقاعدة بيانات سحابية.
